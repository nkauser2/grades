# Grades

Grades reads a file of scores (one per line, 0 to 100) and prints the highest, lowest, and average score, the letter grade for the average, and all the scores in a row. It prints an error message if the file is missing, empty, or has an invalid score.

Requires Python 3 and pytest installed.

## How to run

```
python grades.py scores.txt
```

## How to run the tests

```
python -m pytest
```

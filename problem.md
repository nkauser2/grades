# Problem

Students in a specific class can't easily figure out the particulars about their grades. For example, what is the average score and what letter grade that translates to. Doing it by hand will take up a lot of time and can be subject to mistakes. 


# Initial requirements

**R1**
The program must read scores from a file given on the CL (Command Line). The file is one score per line.

**R2**
The program must print the highest, lowest, and average scores (rounded to two decimal places) in the file.

**R3**
The program must show an error message if the file is missing or a score is not a valid number. The score range is (0-100).

**R4**
The program must say if it encounters an empty file and say "Content Not Found."

**R5**
The program must print a letter equivalent grade for the average found. 59 and below is an F, 69 and below is a D. 79 and below is a C and 89 and below is a B and up to 100 is an A. 

**R6**
The program must print all the scores in a row at the bottom of the file.
